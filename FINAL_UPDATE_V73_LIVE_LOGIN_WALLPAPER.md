# YARIN V73 — Live Login Wallpaper

- Replaced third-party login wallpaper hotlinks with five bundled local Dubai SVG scenes.
- Wallpaper changes every 60 seconds using a soft cross-fade.
- Initial scene follows the current minute, so repeated opens do not always start on the same wallpaper.
- Wallpaper timer pauses while the tab is hidden and resumes cleanly when the user returns.
- Desktop keeps a slow cinematic drift; mobile uses cross-fade only to reduce GPU/battery usage.
- Added reduced-motion support.
- Added wallpaper assets to the PWA static cache and bumped the service worker cache to V73.
